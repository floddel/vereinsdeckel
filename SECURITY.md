# Sicherheit

Du hast eine Sicherheitslücke im Vereinsdeckel gefunden? Danke, dass du hilfst!

**Bitte nicht als öffentliches Issue melden**, sondern vertraulich über GitHub:
Reiter **Security** → **Report a vulnerability** („Private vulnerability reporting“).

Hilfreich sind:
- was betroffen ist (Seite, Schnittstelle, Version),
- wie sich die Lücke nachvollziehen lässt (Schritte, gern mit Testdaten statt echter Vereinsdaten),
- was jemand damit anrichten könnte.

Ich melde mich so bald wie möglich. Behobene Lücken werden in den Versionshinweisen genannt.

Unterstützt wird jeweils die neueste Version.
